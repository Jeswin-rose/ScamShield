
# 🛡️ ScamShield

### Rule-Based Scam Message Detection System

ScamShield is a Python-based web application that identifies potentially suspicious messages using predefined keywords and detection rules.

## Features

- Suspicious keyword detection
- Risk score and risk-level indicator
- Possible scam category identification
- Basic URL warning checks
- Safety recommendations
- SQLite scan history
- Dashboard with scan statistics

## Technologies Used

- Python
- Streamlit
- SQLite
- Regular Expressions

## How to Run

1. Download or clone this repository.
2. Install the required packages:

   pip install -r requirements.txt

3. Run the application:

   streamlit run app.py

## Disclaimer

ScamShield is an educational project. It uses rule-based detection and cannot guarantee that a message or website is safe.

It does not use Artificial Intelligence or Machine Learning.
